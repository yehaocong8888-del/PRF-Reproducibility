# Release Notes

This release was assembled after the Scientific Reports major-revision
experimental cycle.

The release contains publication-facing frozen assets from the original PRF
pipeline, Student distillation/evaluation, external validation, boundary
repair, revision sensitivity studies, efficiency analysis, and representation
baselines.

Same-content historical mirrors were deduplicated by SHA256 without altering
their provenance records.

The public release does not expose absolute local machine paths.
