# Data Availability

The repository does not redistribute third-party raw image datasets.

The released materials contain publication-facing manifests, predictions,
statistics, frozen evaluation contracts, and other small derived artifacts
needed to inspect the reported experiments.

Users should obtain the corresponding public benchmark datasets from their
original providers and follow the frozen protocols and manifests included
under the external-validation and revision-experiment directories.

No historical source asset has been modified to construct this release.
