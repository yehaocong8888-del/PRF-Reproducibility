# Model Availability

The original Student uses the Qwen3-VL-8B-Instruct base model together with
the released LoRA adapter under:

`05_student_lora/final_adapter/original_student/`

The boundary-repaired Student adapter is provided under:

`07_boundary_repair/final_adapter/`

Base foundation-model weights are not redistributed in this repository.
They must be obtained from the original model provider subject to the
provider's license.

Historical intermediate checkpoints and Phase-3 ratio-sensitivity adapters
are not included as release models because they are not the publication-facing
final Student models.
